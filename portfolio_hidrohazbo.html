HIDRO HAZBO

1st Place Winner at OTGET Game Jam 3 🏆. Top-down action roguelike blending dynamic 4x4 biome grid territory control with intense, pattern-driven boss encounters.

🏆 1st Place Winner (OTGET Jam 3) Action Roguelike Unity 2D Dynamic Grid Simulation State-Machine Boss AI Game Juice & Cinemachine

Overview

HIDRO HAZBO is an adrenaline-fueled top-down roguelite centered around water equilibrium and ecological territory control. Players must manage hydration levels across an interactive 4x4 biome grid, cultivating and permanently locking forest tiles while fighting off relentless waves of arid monsters.

The experience culminates in a cinematic multi-pattern boss encounter built on a flexible Finite State Machine (FSM) architecture that demands precise player positioning, spatial awareness, and quick reflex resource management.

Key Technical Contributions & Architecture

  • Dynamic Biome Grid Simulation: Engineered a real-time 4x4 biome grid where individual tiles dynamically transition between states (Drought → Forest → Swamp) based on continuous moisture diffusion and player abilities.
  • Finite State Machine (FSM) Boss AI: Developed a multi-phase boss encounter with modular states including targeted AoE telegraphs, high-velocity charge attacks, and bullet-hell projectile rings.
  • Modular Combat & Damage Architecture: Programmed a decoupled Health & Damage component system supporting invincibility frames (i-frames), damage type resistance, and decoupled UI event buses.
  • Cinematic Presentation & Cinemachine: Directed procedural camera shake impulses, target tracking blends, and arena zoom sequences that punctuate major boss phases.
  • Roguelite Upgrade Progression: Built randomized reward well spawners tied directly to grid biome locking milestones, offering dynamic build variety per run.
